============================================================

&#x20;               **BASIC LINUX COMMANDS**

============================================================



This file contains basic Linux terminal commands studied in Operating System Lab.





\-------------------- **FILE \& FOLDER COMMANDS** -----------------



**1) mkdir foldername**

&#x20;  : To create a new folder.



**2) touch file.txt**

&#x20;  : To create a new empty file.



**3) rm file.txt**

&#x20;  : To delete a file.



**4) rmdir foldername**

&#x20;  : To delete an empty folder.



**5) rm -r foldername**

&#x20;  : To delete a folder and its contents.



**6) mv oldname newname**

&#x20;  : To rename a file or folder.



**7) cp file1.txt file2.txt**

&#x20;  : To copy a file.



**8) mv file.txt foldername/**

&#x20;  : To move a file to another folder.





\-------------------- **DIRECTORY COMMANDS** ---------------------



**9) ls**

&#x20;  : To display files and folders in the current directory.



**10) ls -l**

&#x20;   : To display files and folders with detailed information.



**11) cd foldername**

&#x20;   : To change to a specific directory.



**12) cd ..**

&#x20;   : To move to the parent directory.



**13) cd /**

&#x20;   : To move to the root directory.



**14) pwd**

&#x20;   : To display the current directory path.



**15) clear**

&#x20;   : To clear the terminal screen.





\-------------------- **FILE EDITING COMMANDS** ------------------



**16) nano file.txt**

&#x20;   : To open a file for writing or editing.



**17) cat file.txt**

&#x20;   : To display the contents of a file.



**18) echo "Hello" > file.txt**

&#x20;   : To create a file and write text into it.





\-------------------- **DATE \& TIME COMMANDS** -------------------



**19) date**

&#x20;   : To display the current date and time.



**20) cal**

&#x20;   : To display the calendar.





\-------------------- **SYSTEM COMMANDS** ------------------------



**21) whoami**

&#x20;   : To display the current logged-in user.



**22) uname**

&#x20;   : To display basic system information.



**23) uname -a**

&#x20;   : To display detailed system information.



**24) hostname**

&#x20;   : To display the computer name.



**25) uptime**

&#x20;   : To display how long the system has been running.



**26) shutdown now**

&#x20;   : To shut down the system.



**27) reboot**

&#x20;   : To restart the system.





\-------------------- **NETWORK COMMANDS** -----------------------



**28) ip addr**

&#x20;   : To display network information.



**29) ping google.com**

&#x20;   : To check network connectivity.





\-------------------- **OTHER COMMANDS** -------------------------



**30) history**

&#x20;   : To display previously used commands.



**31) man command**

&#x20;   : To display the manual or help for a command.



**32) echo "Hello"**

&#x20;   : To display text on the terminal.



**33) exit**

&#x20;   : To close the terminal session.
