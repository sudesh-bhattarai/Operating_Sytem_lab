============================================================

&#x20;             **BASIC WINDOWS COMMANDS**

============================================================



This file contains basic Windows Command Prompt (CMD) commands studied in Operating System Lab.





\-------------------- **FILE \& FOLDER COMMANDS** -----------------



**1) mkdir foldername**

&#x20;  : To create a new folder.



**2) type nul > file.txt**

&#x20;  : To create a new empty file.



**3) del file.txt**

&#x20;  : To delete a file.



**4) rmdir foldername**

&#x20;  : To delete an empty folder.



**5) rmdir /s foldername**

&#x20;  : To delete a folder and its contents.



**6) ren oldname newname**

&#x20;  : To rename a file or folder.



**7) copy file1.txt file2.txt**

&#x20;  : To copy a file.



**8) move file.txt foldername**

&#x20;  : To move a file to another folder.





\-------------------- **DIRECTORY COMMANDS** ---------------------



**9) dir**

&#x20;  : To display files and folders in the current directory.



**10) cd foldername**

&#x20;   : To change to a specific directory.



**11) cd ..**

&#x20;   : To move to the parent directory.



**12) cd \\**

&#x20;   : To move to the root directory.



**13) cls**

&#x20;   : To clear the Command Prompt screen.





\-------------------- **FILE EDITING COMMANDS** ------------------



**14) notepad file.txt**

&#x20;   : To open a file in Notepad for writing or editing.



**15) type file.txt**

&#x20;   : To display the contents of a file.



**16) echo Hello > file.txt**

&#x20;   : To create a file and write text into it.





\-------------------- **DATE \& TIME COMMANDS** -------------------



**17) date**

&#x20;   : To display or change the system date.



**18) time**

&#x20;   : To display or change the system time.





\-------------------- **SYSTEM COMMANDS** ------------------------



**19) shutdown /s /t 0**

&#x20;   : To shut down the computer immediately.



**20) shutdown /r /t 0**

&#x20;   : To restart the computer immediately.



**21) systeminfo**

&#x20;   : To display detailed system information.



**22) hostname**

&#x20;   : To display the computer name.





\-------------------- **WI-FI COMMANDS** -------------------------



**23) netsh wlan show profiles**

&#x20;   : To display saved Wi-Fi network profiles.



**24) netsh wlan show profile name="WiFiName" key=clear**

&#x20;   : To display information about a saved Wi-Fi network

&#x20;     including its saved password.





\-------------------- **NETWORK COMMANDS** -----------------------



**25) ipconfig**

&#x20;   : To display basic network information.



**26) ping google.com**

&#x20;   : To check network connectivity.





\-------------------- **OTHER COMMANDS** -------------------------



**27) echo Hello**

&#x20;   : To display text on the screen.



**28) exit**

&#x20;   : To close the Command Prompt.
